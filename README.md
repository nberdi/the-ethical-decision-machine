# The Ethical Decision Machine

A static, interactive web project inspired by **Morality, Law & Philosophy**.

This site presents classic moral dilemmas and lets users compare their choices through multiple ethical frameworks:

- Utilitarianism
- Deontology
- Virtue Ethics
- Civil Disobedience & Justice
- Care Ethics

## Project Structure

- `index.html`
- `style.css`
- `script.js`
- `philosopher.png`
- `README.md`

## Dilemmas Included

1. The Trolley Problem
2. Lying to Protect a Friend
3. Breaking an Unjust Law
4. Stealing Medicine to Save a Life
5. AI Replacing Human Workers
6. Punishment vs Rehabilitation
